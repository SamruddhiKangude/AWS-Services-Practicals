## 🚀----- Step-by-Step: GitHub → AWS Amplify Deployment Workflow -----

### 🧩 Step 1: Build the Application

* Developed a **responsive portfolio website** using **React.js**
* Implemented UI using **HTML, CSS, and JavaScript**

### 🗂️ Step 2: Version Control with GitHub

* Created a **GitHub repository**
* Pushed the complete project source code to GitHub
* Managed updates using commits and branches

### ☁️ Step 3: Access AWS Amplify

* Logged in to the **AWS Management Console**
* Navigated to the **AWS Amplify** service
* Selected **“Host a web app”** to begin deployment

### 🔗 Step 4: Connect GitHub Repository

* Chose **GitHub** as the source provider
* Authorized AWS Amplify to securely access the GitHub account
* Selected the **repository** and **branch (main)** for deployment

### ⚙️ Step 5: Configure Build & CI/CD

* Amplify **automatically detected React build settings**
* Enabled **CI/CD pipeline**
* Configured build and deploy phases without manual setup

### 🚀 Step 6: Deploy the Application

* Initiated the deployment process
* AWS Amplify built and deployed the application
* Monitored build logs and deployment status

### 🔁 Step 7: Continuous Deployment

* Every new **GitHub commit** triggers:

  * Automatic build
  * Automatic deployment
* Ensures the live website stays **up-to-date**

### 🌐 Step 8: Access Live Website

* Successfully accessed the website using the
  **AWS Amplify-generated URL**
* Website is **secure, scalable, and publicly accessible**
