# 📌 Amazon RDS (Relational Database Service) and SQL – Hands-on!

This project demonstrates a hands-on implementation of **Amazon RDS (MySQL)** and SQL using **MySQL Workbench**.

---

## 🔹 Overview

In this demo, I configured an Amazon RDS MySQL instance, connected it using MySQL Workbench, and performed SQL operations including database creation, table relationships, and JOIN queries.

---

## 🛠️ Step 1 – Create an RDS Instance on AWS

- **Engine:** MySQL  
- **Instance Name:** database-1  
- **Username:** admin  
- **Password:** your_password_here (demo purpose)  
- **Public Access:** Enabled  

---

## 🔌 Step 2 – Connect Using MySQL Workbench

- **Endpoint:** your-db-endpoint.rds.amazonaws.com  
- **Port:** 3306  
- **Username:** admin  
- **Password:** your_password_here  

---

## 🗄️ Step 3 – Database & Tables

Created a database with three relational tables:

- `users`  
- `products`  
- `orders`  

These tables are connected using **foreign keys** to demonstrate relational database design.

---

## 📊 Step 4 – SQL Operations

- Inserted sample data into all tables  
- Executed JOIN queries to retrieve user order information  
- Combined multiple tables into a single result set  

---

## ✨ Key Takeaways

- Amazon RDS simplifies launching, managing, and scaling relational databases  
- SQL enables efficient manipulation and structured data analysis  
- MySQL Workbench provides an easy-to-use interface for database interaction
